# Obrázky a screenshoty pro Wiki

Tato složka obsahuje grafická aktiva a screenshoty používané ve Wiki.

## Očekávané soubory screenshotů:
- `screenshot-dark.png` – Screenshot tmavého motivu (VS Code / Desktop prostředí).
- `screenshot-light.png` – Screenshot světlého motivu (VS Code / Desktop prostředí).

## Stávající grafická aktiva:
- `osiris-logo.svg` – Vektorové logo OSIRIS (trojúhelníkový krystal cyan / rose).
- `osiris-app-icon.png` – Aplikační ikona (512x512).
- `letterpress-dark.png` – Tmavý letterpress vodoznak značky OSIRIS.
- `letterpress-light.png` – Světlý letterpress vodoznak značky OSIRIS.
