# Changelog

All notable changes to `osiris-themes` are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/); versioning: [SemVer](https://semver.org/).

## [Unreleased]

### Added
- **Design system**
  - `assets/tokens.json` — machine-readable single source of truth for the whole
    OSIRIS visual language (dark + light).
  - `docs/DESIGN_SYSTEM.md` — human spec (ramp, text, syntax, states, shape,
    component contract, typography).
  - `docs/preview/` — the interactive VS Code-window reference, split into
    `index.html` / `styles.css` / `app.js`; published to GitHub Pages.
- **VS Code** — `Osiris Dark` + `Osiris Light` color themes (`vscode/`), packaged
  as `osiris-theme-<ver>.vsix`.
- **Iconography** — Material Symbols icon language (`assets/tokens.json → icon`,
  `docs/ICONOGRAPHY.md`). Single glyph source `iconography/glyphs.json` (~145
  primitives) + `iconography/map/{filetypes,xdg,producticons}.json`, expanded by
  `scripts/lib/gen_icons.py`.
  - **VS Code file icon theme** — `Osiris File Icons`: ~250 icon definitions,
    ~155 extensions, ~48 filenames, folder/language associations, dark+light.
  - **VS Code product icon theme** — `Osiris Product Icons`: `osiris-symbols.woff`
    (fantasticon) mapping ~400 product-icon ids (activity bar, status bar,
    editor, SCM, debug, test, search, symbols …).
  - **XDG icon theme** — `Osiris`: full freedesktop layout (`index.theme` with
    16/24/32/48/64/128 + `scalable/` across all 8 contexts), ~380 icons + ~310
    GNOME↔KDE compatibility symlinks, `Inherits=Adwaita,breeze,gnome,hicolor`.
    Packaged as `osiris-icon-theme` (deb/rpm).
- **Browsers** — static themes from the token ramp (`browsers/`):
  `chromium-{dark,light}` (Manifest V3 `theme`) and `firefox-{dark,light}`
  (Manifest V2 `theme`), shipped as `osiris-<engine>-<variant>-<ver>.zip`.
- **Terminal** — 16-colour ANSI palette (`assets/tokens.json → terminal`,
  mirroring the VS Code `terminal.ansi*` values), generated by
  `scripts/lib/gen_terminal.py` into GNOME Terminal dconf profiles + merge
  installer, an `org.gnome.Ptyxis` `.palette`, and Konsole `.colorscheme` files.
  Packaged into `osiris-theme-gtk` (Ptyxis) and `osiris-theme-plasma` (Konsole).
- **VitePress** — `osiris-vitepress-theme` npm package (`vitepress/`): dual-accent
  override of the VitePress default theme (`--vp-c-*` tokens, custom blocks,
  home-hero gradient, signature accent touches), dark + light.
- **Bootstrap 5** — `osiris-bootstrap-theme` npm package (`bootstrap/`): Sass
  variable overrides + `[data-bs-theme="dark"]` color mode compiled to a full
  `dist/osiris-bootstrap.css` bundle; ships the `scss/` source too.
- **GTK** — GTK 3, GTK 4 / libadwaita named-colour + widget stylesheets
  (`desktop/gtk-*`, `desktop/gtk-common/`), assembled into `Osiris` /
  `Osiris-Light` themes; `osiris-gtk-theme` helper for the libadwaita opt-in.
- **GNOME Shell** — templated theme (`desktop/gnome-shell/gnome-shell.css.in`)
  covering panel, quick settings, calendar/notifications, OSD, overview
  search/dash, app grid, switchers, modal dialogs and the lock screen.
- **Metacity / Marco** — `desktop/metacity-1/metacity-theme-3.xml.in` rendered
  per variant into `Osiris{,-Light}/metacity-1/` (GNOME Flashback, MATE, Xorg
  fallback) — accent-bar titlebar, rounded top corners, coloured window buttons.
- **GtkSourceView** — `scripts/lib/gen_sourceview.py` turns `themes.<v>.syntax`
  into `osiris` / `osiris-light` style schemes for GNOME Text Editor, gedit,
  GNOME Builder, meld, gnome-latex (shipped to `gtksourceview-5/4/3.0/styles/`
  by `osiris-theme-gtk`).
- **KDE Plasma / Qt** — Plasma colour schemes, Kvantum `OsirisDark` /
  `OsirisLight` (`.kvconfig` + generated element SVG), `OsirisDark` Aurorae
  decoration, `Osiris` Plasma desktop theme.
- **GRUB2** — `boot/grub/theme.txt`, generated background + boot-menu icons +
  9-slice pixmaps, Fira Code `.pf2` generation, `install.sh`.
- **Wallpapers** — `Abstract Bloom` and `Ancient Egypt Sci-Fi`, each Day/Night at
  3840×2160 / 2560×1440 / 1920×1080 / 1366×768, plus GNOME time-of-day dynamic
  XML and KDE light/dark wallpaper packages (`scripts/generate-wallpapers.py`).
- **Build & packaging**
  - `Makefile` + `scripts/build.sh` orchestrator, `scripts/install-local.sh`.
  - Debian source package → `osiris-theme-gtk`, `osiris-theme-plasma`,
    `osiris-icon-theme`, `osiris-theme-grub`, `osiris-wallpapers`,
    `osiris-desktop-theme` (meta).
  - RPM spec with the matching subpackage split.
  - GitHub Actions: `build.yml` (token guard, vsix, npm, deb, rpm, Pages) and
    `release.yml` (tag `v*` → GitHub Release with every artifact, npm publish,
    Pages deploy).
